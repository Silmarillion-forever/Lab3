## Что делает программа

Консольное приложение на C# (.NET 9) с текстовым меню:

| Пункт меню | Действие |
| --- | --- |
| 1. Отгадай ответ | по введённым `a` и `b` вычисляет `f = sin((a³ + b⁵) / 2π) + ∛cos(a + b)`, ответ округляется до двух знаков; даётся 3 попытки угадать |
| 2. Об авторе | выводит ФИО и номер группы |
| 3. Сортировка массива | создаёт случайный массив, копирует его и сортирует копии гномьей сортировкой и сортировкой Шелла, замеряет время через `Stopwatch` и сравнивает результаты |
| 4. Выход | выход из программы с подтверждением |

Предусмотрена обработка ошибок ввода (повторный запрос значения) и деления на ноль.

## Структура проекта

- `GitHubTest/Lab3.cs` — логика лабораторной: меню, алгоритмы сортировки, ввод и вывод
- `GitHubTest/Program.cs` — точка входа приложения
- `GitHubTest.sln` — решение для Visual Studio

## Запуск

```bash
dotnet run --project GitHubTest
```
